# 🚀 TECHFEST — 3D Interactive Experience

An immersive, futuristic 3D website concept designed for IIT Bombay Techfest, combining interactive 3D visuals, scroll-based animations, and dynamic transitions to create an engaging digital experience.

## ✨ Features

* Immersive 3D visual environment
* Interactive 3D objects
* Scroll-driven animations and camera transitions
* Smooth section transitions
* Futuristic UI with neon accents
* Responsive web design
* Engaging visual effects and animations

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Three.js
* GSAP and ScrollTrigger (if used in the project)

## 🎯 Project Objective

To design and develop an interactive 3D web experience that explores creative web design, immersive environments, and dynamic user interactions for a technology festival.

## 🚀 Getting Started

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Install any dependencies required by the project.
4. Run the website using your development server.
5. Explore the 3D environment and interactive animations.
